# Future Roadmap

**Status:** current after v5.4.0

Priorities are suggestions, not commitments.

## Near term

- [ ] Complete a manual VoiceOver/NVDA accessibility pass.
- [ ] Retire legacy `executive.css` through measured extraction and regression testing.
- [ ] Self-host fonts to remove the remaining typography CDN dependency.
- [ ] Expand Open Graph metadata consistently across all non-gallery routes.
- [ ] Add maintained visual regression screenshots for key phone/desktop states.
- [ ] Generate WebP/AVIF derivatives for large photography while retaining fallbacks.

## Medium term

- [ ] Generate image derivatives automatically on asset updates.
- [ ] Add optional privacy-friendly analytics if there is a real reporting need.
- [ ] Add additional verified articles/newsletters as source URLs become available.
- [ ] Add structured event/speaking archive data if the volume grows.

## Longer term

- [ ] Evaluate bilingual EN/SW presentation.
- [ ] Evaluate a lightweight CMS only if non-developer editing becomes a real requirement.
- [ ] Consider automated sitemap generation if routes/content become dynamic.
- [ ] Consider offline/PWA caching only if user behavior justifies it.

## Explicit non-goals

- framework rewrite without a product reason,
- authenticated community,
- e-commerce,
- decorative motion for its own sake.
